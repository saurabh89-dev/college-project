# EchoLoop

College project: a Java real-time chat application with MySQL and basic AI features.

## Files

- `ChatServer.java` - chat server
- `ChatClient.java` - chat client
- `DatabaseConnection.java` - MySQL connection
- `LoginScreen.java` - login/register screen
- `ChatScreen.java` - chat screen
- `KeywordExtractor.java` - AI keyword feature
- `ChatSummarizer.java` - AI summary feature
- `database.sql` - MySQL tables
